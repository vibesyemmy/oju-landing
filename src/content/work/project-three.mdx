## Design

### What we drew

Four teams, four button components, three of them inaccessible. We audited what
existed, found the 68 patterns that actually recurred, and drew one set — with
the failure states the old libraries had never covered.

<div class="placeholder" style="height: 460px">The component set, with states</div>

## Build

### What we shipped

Tokens generate both the Figma library and the CSS, so design and code cannot
diverge. Every component ships behind a CI gate that checks contrast and focus
order — the clinical audit was a deadline, so it became a build step.

<div class="placeholder" style="height: 400px">Token pipeline — Figma to CSS to Storybook</div>

## Outcome

Sixty-eight components replaced four libraries, the clinical accessibility audit
passed on first submission, and new surfaces now ship about three weeks faster.
